5 MCP Tools

Everything you need for outbound

Five focused tools that cover the full B2B sales workflow, available as MCP tools in any compatible client.

🎯
build_icp

Build Your ICP

Define your Ideal Customer Profile — industry, company size, pain points, buyer personas — and store it as context for lead scoring.

🔍
research_prospect

Research Prospects

Pull verified buying signals, recent news, funding rounds, and tech stack data for any company or contact.

📊
score_lead

Score Leads

Get a 0–100 ICP fit score for any prospect, with a breakdown of what signals drove the score.

✉️
draft_outreach

Draft Outreach

Generate personalised cold emails and LinkedIn messages using the 1-3-1 framework, grounded in real prospect signals.

🔄
build_sequence

Build Sequences

Create complete multi-touch outreach sequences with timing, channel mix, and follow-up logic tailored to your ICP.

🛡️

Human approval required before anything is sent

mach-gtm-mcp never sends a message autonomously. Every draft requires explicit approval — you stay in control at all times.

Setup

Up and running in 60 seconds

No API key, no account, no configuration file needed.

1

Add the MCP server to your client

Run npx mach-gtm-mcp or add it to your Claude Code / Cursor MCP config.

2

Build your ICP

Tell your agent your target customer. It calls build_icp and saves the profile for scoring.

3

Research and score

Give a company name. The agent researches it, scores fit 0–100, and explains why.

4

Draft outreach — you approve

Get a personalised email or LinkedIn message drafted. Review it, edit it, then send from your own tool.
